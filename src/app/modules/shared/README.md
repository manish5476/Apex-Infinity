# 🗃️ Shared Components & Utilities

The **Shared Module** contains reusable UI components, pipes, and directives that are used across all other business modules in the Apex Infinity ERP.

---

## 🚀 Key Features

### 🧩 Reusable Components
- **Data Tables**: Standardized AG-Grid and PrimeNG based table configurations.
- **Form Controls**: Custom input wrappers, date pickers, and select menus.
- **Layout Elements**: Cards, dividers, and loading indicators.

### 🛠️ Technical Overview
- **Pipes**: Specialized pipes for currency formatting, date manipulation, and compact numbers.
- **Directives**: Common behavior modifiers for UI interaction.
