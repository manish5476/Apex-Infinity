# 🏦 Accounts Management

The **Accounts Module** handles the core financial identity and categorization for the Apex Infinity ERP. It defines the chart of accounts and the fundamental structure for all financial transactions.

---

## 🚀 Key Features

### 📋 Chart of Accounts
- **Account Categorization**: System-set and user-defined accounts.
- **Organization Sync**: Multi-tenant support with organization-specific account mapping.

### 🛠️ Technical Overview
- **Models**: Defines the `Account` interface used across all finance modules.
- **Routing**: Integrated via `accounts.routes.ts`.
