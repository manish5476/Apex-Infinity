# 🛍️ Public Storefront (Customer View)

The **Storefront Public Module** is the customer-facing interface of the Apex Infinity ecosystem, allowing users to browse products, view details, and interact with the brand.

---

## 🚀 Key Features

### 🛒 Customer Experience
- **Product Listing**: Dynamic grid and list views of all available products.
- **Product Details**: Deep-dive views with images, specifications, and availability.
- **Dynamic Pages**: CMS-driven pages (Home, About, Contact) managed via the Admin panel.
- **Organization Branding**: Automatic theme and content adjustment based on the target organization (`orgSlug`).

### 🛠️ Technical Overview
- **Routing**: Sophisticated routing structure handles dynamic page and product slugs.
- **Master Layout**: Implements the Master Layout pattern for consistent navigation.
- **Components**: Optimized for performance and readability.
