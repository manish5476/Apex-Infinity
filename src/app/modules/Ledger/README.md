# 📖 Financial Ledger

The **Ledger Module** is the core of the Apex Infinity accounting system, providing a double-entry bookkeeping engine that tracks all financial movements across the organization.

---

## 🚀 Key Features

### 🏦 Double-Entry Engine
- **Journal Entries**: Manual and automated entry creation.
- **Trial Balance**: Real-time generation of trial balances and financial statements.
- **Audit Trails**: Complete history of all modifications to ledger entries.

### 🛠️ Technical Overview
- **Service**: `FinancialService` provides the primary interface for ledger interactions.
- **Component**: Central `LedgerComponent` for viewing and managing accounts.
