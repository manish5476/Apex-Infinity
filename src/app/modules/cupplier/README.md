# 🤝 Supplier Management

The **Supplier Module** (internally `cupplier`) maintains the database of all external vendors and service providers, tracking their performance and transaction history.

---

## 🚀 Key Features

### 👤 Vendor Profiles
- **Master Data**: Complete contact and financial details for each supplier.
- **Transaction History**: Integrated view of all historical purchases and payments.
- **Compliance Tracking**: Monitoring of supplier terms and active contracts.

### 🛠️ Technical Overview
- **Routing**: `supplier.routes.ts` manages the vendor dashboard and detail views.
- **Service**: Dedicated `SupplierService` for all vendor-related data operations.
