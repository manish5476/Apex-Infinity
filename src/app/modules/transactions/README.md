# 🔄 Transaction History

The **Transactions Module** provides a centralized interface for viewing and auditing all financial activities involving customers and suppliers.

---

## 🚀 Key Features

### 🔍 Unified Audit Log
- **Customer Transactions**: Detailed history of all sales, payments, and refunds.
- **Supplier Transactions**: Tracking of all purchases, bills, and disbursements.
- **System Logs**: Internal logs of financial state changes.

### 🛠️ Technical Overview
- **Service**: `TransactionService` manages all `/v1/transactions` endpoints.
- **Organization**: Features specialized sub-components for Customer and Supplier tracking.
