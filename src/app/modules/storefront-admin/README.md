# ⚙️ Storefront Administration

The **Storefront Admin Module** provides the tools needed to build, customize, and manage the public-facing store of the organization.

---

## 🚀 Key Features

### 🏗️ Store Builder
- **Dynamic Content**: Create and edit landing pages, about pages, and contact sections.
- **Catalog Control**: Choose which products are visible to the public.
- **Branding Sync**: Control the appearance and theme of the Storefront Public view.

### 🛠️ Technical Overview
- **Routing**: Lazy-loaded internal routes for content and product management.
- **Integration**: Works directly with the `storefront-public` module to reflect changes in real-time.
