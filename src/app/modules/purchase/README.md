# 📥 Purchase & Procurement

The **Purchase Module** manages the end-to-end procurement lifecycle, from initial purchase orders to final goods receipt and supplier returns.

---

## 🚀 Key Features

### 📅 Procurement Workflow
- **Purchase Orders (PO)**: Creation and approval of formal orders to suppliers.
- **Goods Receipt (GR)**: Tracking of physical items received against open orders.
- **Purchase Returns**: Managing the return of defective or incorrect items with full credit tracking.

### 🛠️ Technical Overview
- **Service**: `PurchaseService` provides a comprehensive API for procurement operations.
- **Routing**: Complex routing for forms, details, and returns handled by `purchase.routes.ts`.
