# 👤 User & Workforce Management

The **User Module** handles the internal directory of employees and system users, managing their profiles and role assignments.

---

## 🚀 Key Features

### 👤 Profile Control
- **Employee Directory**: Unified view of all internal users with search/filter capabilities.
- **Status Tracking**: Monitor Active, On-boarding, and Terminated statuses.
- **Profile Synchronization**: Integrated with HRMS for seamless workforce management.

### 🛠️ Technical Overview
- **Routing**: Managed by `user.routes.ts`.
- **Service**: `UserService` handles the internal user directory API.
