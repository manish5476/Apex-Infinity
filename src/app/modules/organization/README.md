# 🏛️ Organization & Tenant Management

The **Organization Module** allows administrators to configure global system settings, branding, and role-based access control (RBAC).

---

## 🚀 Key Features

### ⚙️ Global Configuration
- **Org Settings**: Manage branding (logo, colors), contact info, and operational defaults.
- **Ownership Transfer**: Specialized tools for transferring organization management.
- **Asset Lists**: Centralized tracking of physical and digital organizational assets.

### 👥 Role Management (RBAC)
- **Granular Permissions**: Define custom roles and assign specific module access.
- **Member Invitations**: On-board new members into the organization hierarchy.

### 🛠️ Technical Overview
- **Components**: Centralized `OrgSettingsComponent` and `RoleManagementComponent`.
- **Routing**: Integrated under `/admin` paths in `app.routes.ts`.
