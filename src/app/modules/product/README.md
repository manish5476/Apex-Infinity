# 📦 Product & Inventory Management

The **Product Module** handles the core catalog of items, services, and assets managed within the Apex Infinity ERP. It provides granular tracking of SKUs, pricing, and inventory levels.

---

## 🚀 Key Features

### 🛒 Catalog Management
- **SKU Tracking**: Detailed management of product variants, categories, and attributes.
- **Pricing Engine**: Support for multiple price lists (Retail, Wholesale, etc.).
- **Inventory Monitoring**: Real-time tracking of stock levels across different branches.

### 🛠️ Technical Overview
- **Service**: `ProductService` manages all `/v1/products` endpoints.
- **Routing**: Internal routing handled by `product.routes.ts`.
