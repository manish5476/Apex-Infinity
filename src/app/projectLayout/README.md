# 🍱 Main Application Layout

The **Project Layout Module** defines the skeleton of the secure ERP application, including the sidebar, top header, and main content area.

---

## 🚀 Key Features

### 🏗️ Structural Components
- **Main Screen**: The primary container for the authenticated app experience.
- **Navigation Sidebar**: Collapsible menu for switching between business modules.
- **Header**: Contains user profiles, organization selectors, and global search.

### 🛠️ Technical Overview
- **Standalone Components**: Optimized for fast loading and clear separation of concerns.
- **Responsive Design**: Automatically adjusts for Mobile and Desktop views.
