# ⚙️ Utility Components

The **UtilityComponents Module** contains foundational building blocks that assist in specialized data visualization and interactive UI elements.

---

## 🚀 Key Features

### 🧩 Core Utilities
- **Data Visualizers**: Custom chart wrappers and specialized numeric formatters.
- **Interaction Helpers**: Modals, tooltips, and popover components used for detail-heavy views.
- **System Helpers**: Context menus and specialized button types for bulk actions.

### 🛠️ Technical Overview
- **Modular Design**: Components are decoupled for easy reuse across different business domains.
- **Styling**: Leverages PrimeNG and Vanilla CSS for maximum flexibility.
